WHAT IS THIS DISK?
------------------

This read-only disk is built into the SideTNFS firmware.

It is always available, even when no SD card is inserted
or no TNFS server can be reached.

Run SIDETNFS.PRG from this disk to configure:

  * SD and TNFS drive assignments
  * Settings disk drive letter
  * WIFI settings
  * RTC settings


SAVING CHANGES
--------------

Settings are stored inside the Pico's internal flash memory.


PLANNED FEATURES
----------------

  * Floppy drive emulation
  * Advanced RTC with time zone support
  * Atari Falcon support (where technically possible)
